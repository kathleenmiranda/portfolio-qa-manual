# 🔎 Análise de Requisitos

## 1. Objetivo

Analisar as funcionalidades da aplicação Northwind Test Platform
e identificar os requisitos, regras de negócio, fluxos e riscos
que serão considerados no planejamento dos testes.

## 2. Escopo

As funcionalidades analisadas neste projeto são:

- Login
- Cadastro
- Categorias
- Produtos
- Fornecedores

## 3. Abordagem

A análise será realizada a partir da exploração da aplicação,
considerando:

- Fluxos principais;
- Fluxos alternativos;
- Campos obrigatórios;
- Regras de validação;
- Mensagens apresentadas;
- Limites de campos;
- Comportamentos esperados;
- Possíveis riscos.
