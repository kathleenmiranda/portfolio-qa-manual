# BUG-001 — Mensagem incorreta ao informar senha inválida

## 1. Identificação

| Campo | Informação |
|---|---|
| ID | BUG-001 |
| Funcionalidade | Login |
| Caso de teste | CT-LOGIN-002 |
| Severidade | Média |
| Prioridade | Média |
| Status | Aberto |

---

## 2. Título

Sistema apresenta mensagem de usuário não encontrado ao informar senha inválida para usuário cadastrado.

---

## 3. Pré-condição

Possuir um usuário previamente cadastrado e válido.

Usuário utilizado:

`admin@qatest.com`

A validade do usuário foi confirmada previamente por meio do caso de teste CT-LOGIN-001.

---

## 4. Massa de teste

**E-mail:**

`admin@qatest.com`

**Senha válida:**

`Teste@123`

**Senha utilizada no teste:**

`SenhaIncorreta123`

---

## 5. Passos para reprodução

1. Acessar a tela de Login.
2. Informar o e-mail cadastrado:
   `admin@qatest.com`
3. Informar uma senha incorreta:
   `SenhaIncorreta123`
4. Clicar no botão **Entrar**.

---

## 6. Resultado esperado

O sistema deve impedir o acesso e apresentar uma mensagem informando que o e-mail ou a senha são inválidos:

`Email ou senha inválidos`

---

## 7. Resultado obtido

O sistema impede o acesso, porém apresenta a mensagem:

`Usuário não encontrado. Verifique o email ou cadastre-se.`

A mensagem apresentada indica que o usuário não existe, embora o e-mail utilizado pertença a um usuário cadastrado.

---

## 8. Impacto

A mensagem apresentada não representa corretamente a situação ocorrida durante a tentativa de autenticação.

Isso pode induzir o usuário a acreditar que sua conta não está cadastrada, quando, na realidade, o problema está relacionado à senha informada.
