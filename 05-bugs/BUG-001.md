# 🐞 BUG-001 — Mensagem incorreta ao informar senha inválida

## Título

Sistema apresenta mensagem de "Usuário não encontrado" ao informar senha inválida para usuário cadastrado.

## Funcionalidade

Login

## Ambiente

- Aplicação: Northwind Test Platform
- Navegador: Google Chrome
- Tipo de teste: Funcional
- Cenário: Login com senha inválida

## Pré-condições

- Usuário `admin@qatest.com` deve estar cadastrado.
- Usuário deve conseguir realizar login com sua senha válida.

## Massa de teste

**E-mail:**

`admin@qatest.com`

**Senha utilizada:**

`SenhaIncorreta123`

## Passos para reprodução

1. Acessar a tela de Login.
2. Informar o e-mail `admin@qatest.com`.
3. Informar uma senha incorreta.
4. Clicar no botão **Entrar**.

## Resultado esperado

O sistema deve impedir o acesso e apresentar a mensagem:

`Email ou senha inválidos`

## Resultado obtido

O sistema apresenta a mensagem:

`Usuário não encontrado. Verifique o email ou cadastre-se.`

## Evidência

A evidência será adicionada após a captura da execução.

## Severidade

**Média**

## Prioridade

**Média**

## Status

**Aberto**

## Caso de teste relacionado

[CT-LOGIN-002](../02-casos-de-teste/login/casos-de-teste.md)

## Observação

O e-mail utilizado no teste foi validado previamente no cenário CT-LOGIN-001, no qual o login foi realizado com sucesso utilizando a senha válida.

Portanto, o comportamento observado indica uma inconsistência na mensagem apresentada quando um usuário existente informa uma senha incorreta.
