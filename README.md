# 🧪 Portfólio de QA — Testes Manuais

Olá! Eu sou Kathleen, profissional da área de **Quality Assurance**, e este repositório apresenta exemplos práticos de atividades relacionadas à qualidade de software.

O objetivo deste portfólio é demonstrar, por meio de um projeto prático, minha abordagem para **analisar requisitos, elaborar cenários e casos de teste, executar testes manuais, registrar evidências, identificar defeitos e acompanhar seus respectivos retestes**.

---

## 🎯 Objetivo do projeto

Demonstrar na prática diferentes etapas do processo de testes de software, incluindo:

* Análise de requisitos;
* Levantamento de cenários;
* Elaboração de casos de teste;
* Testes funcionais;
* Testes positivos e negativos;
* Testes de validação;
* Testes de limite;
* Testes exploratórios;
* Execução manual;
* Registro de evidências;
* Reporte e acompanhamento de defeitos;
* Reteste;
* Testes de regressão;
* Testes de API.

---

## 🧩 Aplicação utilizada

Os testes deste portfólio serão realizados em uma aplicação web utilizada para fins de estudo e demonstração de práticas de QA.

As funcionalidades inicialmente abordadas serão:

| Módulo         | Funcionalidades                  |
| -------------- | -------------------------------- |
| 🔐 Login       | Autenticação e validações        |
| 👤 Cadastro    | Criação de usuários e validações |
| 🗂️ Categorias | Cadastro, edição e validações    |

---

## 🔎 Processo de testes

O projeto seguirá o seguinte fluxo:

```text
Análise do requisito
        ↓
Levantamento de cenários
        ↓
Elaboração dos casos de teste
        ↓
Preparação da massa
        ↓
Execução
        ↓
Registro das evidências
        ↓
Identificação de defeitos
        ↓
Reporte do bug
        ↓
Correção
        ↓
Reteste
        ↓
Regressão
        ↓
Relatório final
```
