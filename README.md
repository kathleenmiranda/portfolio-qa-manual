# 🧪 Portfólio de QA — Testes Manuais

Olá! Eu sou Kathleen, profissional da área de **Quality Assurance**, e este repositório apresenta um projeto prático desenvolvido para demonstrar atividades relacionadas à **qualidade de software e testes manuais**.

O projeto foi estruturado com base em um fluxo de trabalho de QA, contemplando desde a análise de requisitos e a elaboração dos casos de teste até a execução, o registro de evidências, o reporte de defeitos, o reteste e os testes de regressão.

---

## 🎯 Objetivo do projeto

Demonstrar, na prática, diferentes etapas do processo de testes de software, incluindo:

- Análise de requisitos;
- Levantamento de cenários de teste;
- Elaboração de casos de teste;
- Preparação de massa de teste;
- Testes funcionais;
- Testes positivos e negativos;
- Testes de validação;
- Testes de limite;
- Testes exploratórios;
- Execução manual;
- Registro e organização de evidências;
- Identificação e reporte de defeitos;
- Acompanhamento do ciclo de vida dos bugs;
- Reteste após correções;
- Testes de regressão;
- Testes de API;
- Consolidação dos resultados no relatório final.

---

## 🧩 Aplicação utilizada

Os testes deste portfólio são realizados em uma aplicação web utilizada para fins de **estudo e demonstração de práticas de Quality Assurance**.

### Funcionalidades abordadas

| Módulo | Funcionalidades |
|---|---|
| 🔐 Login | Autenticação, validações e navegação |
| 👤 Cadastro | Criação de usuários e validações |
| 🗂️ Categorias | Cadastro, edição e validações |
| 📦 Produtos | Cadastro, edição e validações |

> Novos cenários e funcionalidades poderão ser adicionados ao longo da evolução do projeto.
